## 文档维护

- 参数及奖励语义集中在 `CONFIGURATION.md`；命令集中在训练、评估指南，项目 README 只保留入口。
- 修改奖励、成功判据、课程、动作接口或 CLI 后，同步更新对应文档的日期和数值。
- 旧指南集中存入 `archive/`，加归档日期、原路径和当前入口链接；历史实验结果保留当时条件。
- 实验记录写清 checkpoint、数据版本、代码版本、阶段、回合时限、种子和评估 JSON；测试入口存在不等于当前版本已通过测试。
